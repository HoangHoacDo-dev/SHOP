## 📖 Giới thiệu dự án

**SHOP** là dự án website bán hàng được xây dựng với ASP.NET Core MVC, nhằm thực hành lập trình web, tìm hiểu mô hình MVC và thiết kế giao diện người dùng.

Dự án là cơ hội để nâng cao kỹ năng lập trình C#, rèn luyện tư duy xây dựng ứng dụng web và từng bước tiếp cận quy trình phát triển phần mềm thực tế.

## ✨ Mục tiêu dự án

- 🎨 Xây dựng giao diện website trực quan, thân thiện.
- 💻 Thực hành lập trình web với C# và ASP.NET Core MVC.
- 🧱 Tìm hiểu cách tổ chức dự án theo mô hình MVC.
- 🔧 Rèn luyện kỹ năng sửa lỗi và quản lý mã nguồn.
- 🚀 Từng bước phát triển thêm các chức năng bán hàng.

## 🚀 Hướng dẫn cài đặt

### 1. Yêu cầu hệ thống

- Đã cài đặt .NET SDK tương thích với dự án.
- Visual Studio hoặc Visual Studio Code.
- Git để tải mã nguồn.

### 2. Tải dự án

Mở Terminal và chạy lệnh:

```bash
git clone https://github.com/HoangHoacDo-dev/SHOP.git
```

### 3. Truy cập thư mục dự án

```bash
cd SHOP
```

### 4. Khôi phục các thư viện

```bash
dotnet restore
```

### 5. Chạy chương trình

Di chuyển vào thư mục chứa tệp `.csproj`, sau đó chạy:

```bash
dotnet run
```

Mở địa chỉ localhost được hiển thị trong Terminal để xem website.
